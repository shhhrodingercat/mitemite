# MiteMite

**TV & anime release tracking for Home Assistant.**

MiteMite follows TV series, tracks episode releases and local watched state, and shows where a series is available to watch in the configured region.

## Status

Early development — MVP 0.1.0.

## Planned MVP

- TMDB API integration with a user-provided API key
- Configurable region and language
- Follow TV series from Home Assistant
- One Home Assistant device per series
- Episode and season data from TMDB
- Local watched/unwatched state
- Next unwatched episode
- Next release date
- Unwatched episode count
- New episode binary sensor
- Streaming providers as series-level metadata
- Home Assistant services to mark episodes watched/unwatched and refresh data

## Requirements

- Home Assistant
- A TMDB API key
